# מסלול דינמי — ליפנו ודרום צ׳כיה (PWA)

כלי אינטרנטי (Progressive Web App) המציג את מסלול הטיול המשפחתי לליפנו ודרום צ׳כיה
(18–23 באוגוסט 2026), עם תחזית מזג אוויר חיה מ־Open-Meteo, המלצות שמתעדכנות
לפי מזג האוויר בפועל בשעות הפעילות של כל יום, ואפשרות שימוש גם ללא אינטרנט.

## מבנה הקבצים

```
├── index.html            # כל האתר — עיצוב, נתוני המסלול והלוגיקה
├── manifest.webmanifest  # הגדרות ה־PWA (שם, צבעים, אייקונים)
├── sw.js                 # Service Worker לשמירה במטמון ולעבודה אופליין
├── icons/
│   ├── icon-192.png      # אייקון 192×192 פיקסלים — חובה לשם זה בדיוק
│   └── icon-512.png      # אייקון 512×512 פיקסלים — חובה לשם זה בדיוק
└── README.md             # הקובץ הזה
```

**חשוב:** ארבעת הקבצים (`index.html`, `manifest.webmanifest`, `sw.js`, ותיקיית
`icons/`) חייבים להישאר **באותה תיקייה יחד**, עם בדיוק אותם שמות — הקוד מפנה
אליהם בנתיבים יחסיים (`./manifest.webmanifest`, `./sw.js`, `./icons/icon-192.png`).

### לגבי האייקונים

צירפתי שני קבצי PNG זמניים (`icons/icon-192.png` ו־`icons/icon-512.png`) — ריבוע
בצבעי האתר עם הכיתוב "LN", רק כדי שהאתר לא יישבר אם אין אייקונים אמיתיים.
אפשר וכדאי להחליף אותם בעתיד באייקון מעוצב, ובלבד שהקבצים החדשים:
- נקראים בדיוק `icon-192.png` ו־`icon-512.png`
- בגודל 192×192 ו־512×512 פיקסלים בהתאמה (ריבועיים, PNG)
- יושבים בתוך תיקיית `icons/`

אם משנים את שמות הקבצים, יש לעדכן בהתאם גם את `manifest.webmanifest` וגם את
תגית ה־`<link rel="icon">` וה־`<link rel="apple-touch-icon">` בתוך `index.html`.

## העלאה ל־GitHub Pages

1. ביצירת ריפוזיטורי חדש ב־GitHub (או שימוש בקיים), להעלות את **כל חמשת
   הפריטים** מהרשימה למעלה (כולל תיקיית `icons` עם שני הקבצים שבתוכה) לתיקיית
   השורש של הריפו (או לתיקיית `docs/` אם כך תבחרו להגדיר בהמשך).
2. להיכנס להגדרות הריפו: **Settings → Pages**.
3. תחת **Build and deployment → Source**, לבחור **Deploy from a branch**.
4. לבחור את הענף (**branch**) שאליו הועלו הקבצים (בדרך כלל `main`), ואת
   התיקייה שבה הם נמצאים (**root** אם הועלו לשורש, או `/docs` אם לשם).
5. לשמור. GitHub ייתן קישור בסגנון:
   `https://USERNAME.github.io/REPO-NAME/`
   הפרסום בפועל עשוי לקחת דקה-שתיים.
6. לפתוח את הקישור בדפדפן — האתר אמור לעלות עם כל התוכן.

### חובה HTTPS

GitHub Pages מספק HTTPS אוטומטית, וזה קריטי: **Service Worker ו־PWA לא
עובדים דרך HTTP רגיל**, רק דרך HTTPS (או localhost בפיתוח מקומי). כל עוד
משתמשים בכתובת ה־github.io הרגילה זה כבר מסודר מאליו.

### הוספה למסך הבית (התקנת ה־PWA)

- **אנדרואיד / כרום:** בתפריט הדפדפן (⋮) לבחור "התקן אפליקציה" / "הוסף למסך
  הבית".
- **iPhone / ספארי:** כפתור השיתוף (הריבוע עם החץ) ← "הוסף למסך הבית".

לאחר ההתקנה האתר ייפתח כאפליקציה עצמאית (בלי סרגל הכתובת של הדפדפן), ויעבוד
גם ללא אינטרנט עם המסלול והתחזית האחרונה שנשמרו.

### עדכון גרסה מאוחר יותר

אם תרצו לעדכן את הקבצים בעתיד (למשל לשנות תוכן במסלול), חשוב לשנות גם את
הערך `CACHE_VERSION` בתחילת `sw.js` (למשל מ־`lipno-trip-v1` ל־`lipno-trip-v2`).
בלי זה, מכשירים שכבר שמרו את האתר במטמון עלולים להמשיך להציג גרסה ישנה. כשיש
גרסה חדשה, האתר יציג לבד באנר "עדכון חדש זמין — טען מחדש".

## מה עובד אופליין ומה לא

- **עובד אופליין:** האתר עצמו (העיצוב, המסלול, רשימת ההזמנות, ה"אופציות
  הנוספות"), וכן **התחזית האחרונה שנשמרה** בפעם האחרונה שהייתה גישה לאינטרנט.
- **לא עובד אופליין:** משיכת תחזית *חדשה* מ־Open-Meteo (זה דורש חיבור בפועל).
  כשאין חיבור, האתר יציג הודעה "אין חיבור — מוצגת התחזית האחרונה שנשמרה"
  ויעבוד עם הנתונים הקיימים.

## נתונים שעדיין דורשים אימות אנושי (לא מגיעים מ־API)

- שעות פתיחה בפועל של Aquapalace Praha, Bikepark, פארק חבלים, Slideland,
  Aquaworld Lipno וכו' — אלה לא מגיעות מ־API חי, והן מוצגות כפי שנמסרו, עם
  קישורים רשמיים לאימות היכן שיש.
- זמינות והזמנת רפטינג/שיט בקרומלוב, מסעדות, אופניים וכו' — דורשות פנייה
  ידנית לספקים.
- זמני נסיעה בפועל (פקקים, חניה) — מומלץ Waze / Google Maps בזמן אמת, בעיקר
  ב־23.8 לפני שתי הטיסות.
- תדלוק והחזרת רכב שכור לפני הטיסות — לא נכלל בחישובי הזמן באתר.

רק **תחזית מזג האוויר עצמה** חיה ומתעדכנת אוטומטית מול Open-Meteo (ללא צורך
במפתח API, ללא עלות).
